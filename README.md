# Projet-DB
# Streaming Platform Database (VoD)

A relational database project simulating a Video-on-Demand (VoD) streaming service (similar to Netflix or Disney+). Built using **LibreOffice Base (HSQLDB)** and **PostgreSQL**, this project manages subscription tiers, main billing accounts, household profiles, a centralized media catalog, and user watch progress.

---

## Project Overview

This database is designed to solve real-world data management challenges for a streaming service:

* **Centralized Billing**: One master account handles payment while supporting multiple sub-profiles.
* **Personalized Profiles**: Separate watching spaces for individual household members (e.g., Kids vs. Adults).
* **Watch Progress Tracking**: Tracks exact playback time in seconds to support "Resume Watching" functionality.
* **Automated Data Maintenance**: Built-in rules automatically clean up sub-profiles and activity when a master account is deleted.

---

## Database Schema

The system consists of **5 relational tables**:

| Table Name | Description | Key Fields |
| --- | --- | --- |
| **`subscriptions`** | Defines paid plan tiers and limits | `plan_id` (PK), `plan_name`, `monthly_price`, `max_screens` |
| **`users`** | Master billing accounts | `user_id` (PK), `plan_id` (FK), `username`, `email` |
| **`profiles`** | Individual household profiles | `profile_id` (PK), `user_id` (FK), `profile_name`, `is_kids` |
| **`media`** | Central video content catalog | `media_id` (PK), `title`, `type`, `release_year`, `duration_minutes` |
| **`watch_history`** | Junction entity tracking views | `history_id` (PK), `profile_id` (FK), `media_id` (FK), `progress_seconds` |

## Getting Started & Execution

### **1. Database Setup (DDL & DML)**

Run the following SQL commands in **Direct SQL Mode** to initialize the schema and populate sample data:

```sql
-- Create Tables
CREATE TABLE "subscriptions" (
    "plan_id" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "plan_name" VARCHAR(50) NOT NULL,
    "monthly_price" DECIMAL(5, 2) NOT NULL CHECK ("monthly_price" >= 0),
    "max_screens" INT NOT NULL CHECK ("max_screens" > 0)
);

CREATE TABLE "users" (
    "user_id" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "plan_id" INT REFERENCES "subscriptions"("plan_id") ON DELETE SET NULL,
    "username" VARCHAR(50) NOT NULL,
    "email" VARCHAR(100) UNIQUE NOT NULL,
    "signup_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE "profiles" (
    "profile_id" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "user_id" INT REFERENCES "users"("user_id") ON DELETE CASCADE,
    "profile_name" VARCHAR(50) NOT NULL,
    "is_kids" BOOLEAN DEFAULT FALSE
);

CREATE TABLE "media" (
    "media_id" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "title" VARCHAR(150) NOT NULL,
    "type" VARCHAR(20) CHECK ("type" IN ('Movie', 'Series_Episode')),
    "release_year" INT CHECK ("release_year" >= 1900),
    "duration_minutes" INT NOT NULL
);

CREATE TABLE "watch_history" (
    "history_id" INT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    "profile_id" INT REFERENCES "profiles"("profile_id") ON DELETE CASCADE,
    "media_id" INT REFERENCES "media"("media_id") ON DELETE CASCADE,
    "watch_date" TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    "progress_seconds" INT DEFAULT 0 CHECK ("progress_seconds" >= 0)
);
```

## Key Demonstration Queries

### **1. Count Profiles Per User Account**

*Calculates how many household sub-profiles each registered user has created.*

```sql
SELECT u."username", u."email", COUNT(p."profile_id") AS total_profiles 
FROM "users" u 
JOIN "profiles" p ON u."user_id" = p."user_id" 
GROUP BY u."username", u."email";

```

### **2. Measure Media Content Popularity**

*Aggregates total view counts across all users for each video title.*

```sql
SELECT m."title", m."type", COUNT(wh."history_id") AS total_views 
FROM "media" m 
JOIN "watch_history" wh ON m."media_id" = wh."media_id" 
GROUP BY m."title", m."type";

```

### **3. Multi-Table User Activity Breakdown**

*Performs a double join to calculate total movies/episodes watched across all sub-profiles per master account.*

```sql
SELECT u."username", u."email", COUNT(wh."history_id") AS total_media_watched 
FROM "users" u 
JOIN "profiles" p ON u."user_id" = p."user_id" 
JOIN "watch_history" wh ON p."profile_id" = wh."profile_id" 
GROUP BY u."username", u."email";

```

### **4. Format Media Titles with String Concatenation**

*Formats media titles alongside their release year into a single unified column.*

```sql
SELECT CONCAT(CONCAT("title", ' ('), "release_year", ')') AS "Full Title" 
FROM "media";

```

### **5. Filter Catalogue with Keyword Search**

*Retrieves all media records matching a specific keyword query.*

```sql
SELECT "title", "type", "release_year", "duration_minutes" 
FROM "media" 
WHERE "title" LIKE '%Cyberpunk%';

```

## Technical Notes & Compatibility

* **LibreOffice Base (HSQLDB)**: When executing queries in LibreOffice Base, make sure to enable the **SQL Direct** icon to prevent graphical parser limitations on multi-table joins and functions.
* **Case Sensitivity**: Double quotes (`""`) are strictly applied around identifiers (tables and columns) to ensure full multi-platform engine compatibility.
* **Integrity Cascades**: `ON DELETE CASCADE` is set on child entities (`profiles`, `watch_history`) to prevent orphaned records upon account deletion.
